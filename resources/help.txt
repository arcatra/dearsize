Help

SYNOPSIS:
-X      : Set explicit, when set print the output in a human readable format.
-v, -V  : Verbose, when set "dearsize" would print out the files, directory list to stdout.
-d, -D  : Decimal conversion basis, when set DearSize would use "Decimal" conversion(1000) to calculate the KB, and MB. and the default being "Binary".

You can use multiple options in a same option, like so: -ve, -vde, ect; The order of the options dosen't matter.
