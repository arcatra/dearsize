NAME
    dearsize - Know the exact size of a directory

SYNOPSIS:
    dearsize path_to_dir [Flags(s)]

DESCRIPTION:
    -v, -V  : Verbose, when set dearsize would list out and prints the files, directory that are currently being processed,
    and some other importent information, to stdout.
    -b, -B  : Apply BINARY conversion basis, when set dearsize would use Binary conversion to calculate the KiB, MiG, GiB (1024 Bytes = 1 KiB..).
    And the default being DECIMAL conversion basis (1000 Bytes = 1 KB..).
    -s, -S  : Set sym link output status to true, when set dearsize would print out the Symbolic Link handling status to stdout.
    -X      : Set explicit to FALSE(0), when set dearsize would print the output in a NON human readable format.
    -h, -H  : Help, activate help for dearsize.

You can use multiple flags in a same flag, like so: -ve, -vde, ect; The order of the flags dosen't matter.
